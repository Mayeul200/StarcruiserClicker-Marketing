# Covers générées (itch.io / CrazyGames / réseaux)

| Fichier | Taille | Usage |
|---|---|---|
| `cover-800x1200.jpg` | 800×1200 (2:3 portrait) | Cover itch.io (officiel 630×500 recommandé, mais 2:3 passe aussi), visuels verticaux stores |
| `cover-800x800.jpg` | 800×800 (carré) | CrazyGames / Poki / réseaux sociaux / og:image alternatif |

Générées depuis les assets du jeu (logo2.webp, Fusée3.webp, parts.webp, fond virgo-cluster2 flouté).
Script inline (PIL) — régénérer en modifiant `make_cover()` si besoin.
