# Covers (itch.io / CrazyGames / réseaux)

| Fichier | Taille | Usage |
|---|---|---|
| `cover-gameplay-800x1200.jpg` | 800×1200 (2:3) | ⭐ Cover recommandée — montre le gameplay (vraies frames du jeu) |
| `cover-gameplay-800x800.jpg` | 800×800 | ⭐ Version carrée CrazyGames / réseaux |
| `cover-800x1200.jpg` | 800×1200 | Cover "marque" simple (logo + fusée) |
| `cover-800x800.jpg` | 800×800 | idem, carré |

Les versions `gameplay` sont composées de vraies frames extraites des séquences vidéo du jeu
(clics, bâtiments, assemblage fusée, décollage) + icônes du jeu (pièce, atelier, usine, Lune, Mars)
sur fond spatial flouté, avec CTA « CLICK. BUILD. LAUNCH. ».
